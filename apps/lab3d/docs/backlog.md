# 남은 일 (빵고양이 과학섬)

2026-11-02 기준, `dev` = `404e02a`. 요청받은 작업은 모두 반영됐다. 아래는 미뤄 두거나 확인이 남은 것이다.

## 남겨 둔 큰 일

- **두 번째 섬(지구과학).** 낮과 밤, 계절, 달의 모양([ADR 0003](../../../docs/adr/0003-one-app-one-island-per-field.md)). 섬 배치는 데이터로 옮겨 두었다(`content/islands/mechanics.json`, `Island`). 남은 것:
  - 섬 고르기(또는 다음 섬으로 넘어가기) 화면
  - 진행 저장의 섬 구분(이야기 표시, 마지막 장소가 지금은 섬 구분 없는 키)
  - 섬별 이야기 파일
  - 강체 없는 실험 기반("모델이 계산하고 3D는 그리기만"), 교과서 값 시험
  - 큰 작업이라 티켓 지도로 나눠 계획부터 잡는다.
- **스토어 출시.** 다른 작업에서 진행 중(PR #40 머지, `feat/play-release`·`feat/play-store-release`).

## 미뤄 둔 결정

- **플레이스토어 대상 연령.** "AI에게 더 물어보기"(AI 앱 공유 창, 웹으로 열기)와 함께 미룸.
- **다른 문자의 언어.** 영어·한국어는 됐다(2026-11-02, [ADR 0004](../../../docs/adr/0004-words-apart-by-language.md)). 일본어·중국어 등은 그 언어 폰트(지금 한글 서브셋만)가 더 필요하다.

## 결정 (기록)

- **과금·하루 제한 없음**(2026-10-30). 어린이 앱이라 전부 무료.
- **별 조각 모양 유지**(2026-10-30).
- **물에 띄우기는 통 뗏목 이야기**(2026-11-02): 조각은 물탱크 바위섬 위, 큰 통에 빵고양이를 태워 건넌다. 예전 보물 상자 건지기는 별 조각 찾기로 어색해서 바꿨다.

## 기기에서 손으로 확인할 것 (테스트·화면 캡처는 통과)

- 설정 → Language로 언어를 바꾼 뒤 지도와 실험(이야기, 단서가 그대로 나오는지). 고친 버그: PR #43.
- 물에 띄우기 새 미션 세 단계와 마지막에 빵고양이가 바위섬으로 건너가는 장면(설정 → 처음부터 다시 하기 뒤).
- 가벼운 통(5 kg)을 물속 깊이 넣고 놓아도 튀지 않는지(PR #41).
- 영어 화면 전체(글 넘침): 예측 단추는 넓어지게 고쳤다. 긴 제목은 `…`로 줄어든다.
