# ADR 0004: 글은 언어 폴더에, 코드와 데이터에는 키만

> **Status:** 채택됨
> **Date:** 2026-11-02

## 맥락

- 다국어를 지원하려면 한국어 글을 바꿔 끼울 수 있어야 한다. 2026-11-02 사용자 결정: "섬 데이터 분리와 언어 분리만 먼저". 영어 글과 언어 설정은 아직 하지 않는다.
- 나누기 전에는 글이 두 곳에 섞여 있었다.
  - 코드: 약 150줄. 단추·설정·사이드바 말, 실험 상태 글, 미션 순서 말, 과학 낱말 목록, 카드 단위 말.
  - 실험 JSON과 `content/story.json`: 약 900줄. 숫자·id와 같은 객체 안에 있었다.

## 검토한 안

| 안 | 장점 | 단점 |
|---|---|---|
| (a) 자체 `Locale`: `ui.json` 키 + 데이터 모양 그대로의 말 파일을 읽을 때 겹침 | 화면 코드는 그대로 정의를 읽는다. 한 언어가 폴더 하나다. 시험으로 키 누락·글 섞임을 막는다 | 겹치는 모양을 데이터와 맞춰야 한다 |
| (b) Godot 번역(`tr()`, CSV/PO, 한국어 원문이 msgid) | 엔진 기능, Control 자동 번역 | JSON 콘텐츠는 그대로 한국어다. 원문을 바꾸면 모든 언어의 키가 바뀐다. 가져오기(import) 단계가 생긴다 |
| (c) 언어마다 실험 JSON을 통째로 복사 | 단순 | 숫자가 언어 수만큼 중복되어 어긋난다 |

## 결정

1. **(a)**를 택한다. 글은 `content/locale/<언어>/`에 있다.
   - 코드의 글: `ui.json`, `Locale.t`·`list`·`map`
   - 실험·이야기의 말: `experiments/<id>.json`, `story.json`
2. 데이터 파일(`content/experiments`, `content/islands`, `content/story.json`)에는 글이 없다. 메모 `about`은 예외다. 시험(`tests/locale_checks.gd`)이 코드와 데이터의 한글 글, 없는 키, 안 쓰는 키를 막는다.
3. 그 언어에 없는 글은 기본 언어(`ko`)의 글이다.

## 결과

- 새 언어는 `content/locale/<언어>/`를 채우는 일이다. 언어 고르기와 폰트(한글 부분 폰트는 쓰는 글자만 담는다)는 그때 더한다.
- 실험 말 파일의 `kid.states`는 실험의 상태 글을 키로 쓴다. 그래서 같은 언어의 `ui.json` 상태 글과 맞아야 한다.
