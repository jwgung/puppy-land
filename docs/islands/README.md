## 섬 공통 규칙

### 아이 화면의 낱말

2026-11-13 사용자 결정(퀴리섬 기획 중 "화학 원소기호나 이런 이름들은 애들한테 어려운데"). 모든 섬에 적용한다.

- **아이 화면에는 생활 낱말만 쓴다.** 소금, 구리(10원짜리 동전 색), 식초, 비누, 거품 기체처럼 아이가 아는 말로 부른다. 조건 단추는 그림으로 보인다.
- **장소마다 굵은 과학 낱말은 하나까지.** 뉴턴섬의 **중력**처럼 처음 나올 때 굵게 쓰고 같은 줄에서 쉬운 말로 풀어 준다.
- **원소기호, 화학식, 물질의 정확한 이름, 숫자 단위는 보호자 노트(`자세히`)에만 둔다.** 예: 아이 화면은 "소금 불꽃", 보호자 노트는 "노란 불꽃은 소금 속 나트륨".
- 이미 있는 규칙과 함께 쓴다: 아이 화면에 숫자 없음, 퍼피는 과학 낱말을 쓰지 않음(`Story.science_words()`), 결과 한 줄에 기호·숫자 없음(`tests/kid_words_checks.gd`, `tests/hands_on_checks.gd`).

### 미션 3단계

- 단계마다 새로 배우는 것이 하나씩 있다. 같은 것을 더 크게·더 많이만 하는 단계는 두지 않는다(2026-11-13 사용자).
- 앞 단계에서 바꾸는 것은 되도록 하나(조건 그림 단추 하나 또는 물체 하나)다.
